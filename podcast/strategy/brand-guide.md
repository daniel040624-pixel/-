# 브랜드 가이드 — 생각의 온도

> 이 문서는 사람(나)과 프로그램(Claude 기획·제목 생성)이 **똑같이** 따르는 기준입니다.
> `python -m studio plan` 과 자동 편집의 제목·설명 생성이 이 파일을 그대로 읽습니다. 바꾸면 바로 반영됩니다.

## 1. 한 문장 정체성

**"생각을 대신해 주지 않고, 생각하게 만드는 친구."**

- 채널 약속: 매일 한 가지, 스스로 생각하게 만드는 질문
- 보는 사람: 20~30대. 열심히 사는데 방향이 흐릿하고, 정답 대신 **자기 기준**을 찾고 싶은 사람
- 보고 나면 얻는 것: ① 새 관점 하나 ② 오늘 해볼 행동 하나 ③ 댓글로 답하고 싶은 질문 하나

## 2. 두 개의 트랙 (메시지)

| | **A 트랙 · 채널의 메시지** | **B 트랙 · 시청자가 원하는 메시지** |
|---|---|---|
| 역할 | 정체성과 팬을 만든다 (왜 이 채널이어야 하는가) | 발견되고 퍼진다 (사람들이 이미 찾고 있는 것) |
| 출발점 | 내 관점, 내 경험, 내가 믿는 것 | 검색어, 댓글 질문, 또래의 흔한 고민 |
| 주제 기둥 | ① 스스로 생각하기 (AI·정보 과잉 시대의 사고력) ② 질문하는 삶 ③ 편안함 vs 성장 ④ 관계와 대화 ⑤ 일과 의미 | ① 진로·불안 ② 인간관계 ③ 자존감·비교 ④ 습관·공부·집중 ⑤ 돈과 행복 ⑥ 번아웃·쉼 |
| 끝맺음 | "저는 이렇게 생각해요. 당신은요?" | "그래서 오늘 이것 하나만 해보세요." |
| 비율 | 1단계 40% → 4단계 50% | 1단계 60% → 4단계 50% |

**두 트랙을 잇는 규칙:** B 트랙(고민 해결)을 다뤄도 결론은 항상 A 트랙의 관점("남의 답보다 내 질문")으로 닫는다. 그래야 어떤 영상으로 들어와도 같은 채널로 기억된다.

## 3. 두 개의 형식

| | **혼자 전달 (solo)** | **대화 담기 (dialogue)** |
|---|---|---|
| 느낌 | 친구에게 진지하게 털어놓는 1:1 | 카페에서 엿듣는 진짜 대화 |
| 기본 길이 | 쇼츠 30~60초 / 롱폼 5~12분 | 쇼츠 1분 / 롱폼 15~30분 |
| 촬영 | 세로, 눈높이, 상반신, 창가 자연광 | 가로, 두 사람이 한 화면, 핀마이크 2개 |
| 구조 | 훅 → 내 경험 → 관점 전환 → 행동 하나 → 질문 | 훅 질문 → 각자 입장 → 부딪힘 → 깨달음 → 시청자에게 질문 |
| 템플릿 | `solo_short`, `solo_long` | `dialogue_short`, `dialogue_long` (롱폼에서 쇼츠 3개 자동 추출) |
| 대화 상대 | — | 친구·선후배·다른 분야 사람 → (3단계부터) 비슷한 규모 크리에이터 |

## 4. 톤앤매너

**말투**
- 존댓말 + 구어체. "~거든요", "~잖아요", "~더라고요"는 OK, 강의체("~해야 합니다") 금지
- 단정 대신 제안: "무조건 ~하세요" ❌ → "저는 ~해봤는데, 이게 꽤 달랐어요" ⭕
- 한 문장 15단어 이내. 어려운 단어는 일상어로 (예: "메타인지" → "내가 뭘 모르는지 아는 것")
- 숫자·사례는 진짜만. 출처를 모르면 "그런 말이 있잖아요" 수준으로만

**하지 않는 것**
- 공포·분노 자극 ("이거 모르면 망합니다"), 남 깎아내리기, 정치·혐오 소재
- 낚시 제목(영상에 없는 내용 약속), 자극적인 썸네일 표정 연출
- "구독 좋아요 눌러주세요" 반복 — 대신 마지막 질문으로 댓글을 부른다

**시그니처 (매 영상 동일하게)**
- 오프닝 없음. **첫 마디가 곧 훅** (인사는 1단계에서도 생략)
- 클로징 문장: **"오늘의 질문, ○○○. 댓글에서 당신 생각을 들려주세요."**
- 롱폼 시작 문장: "오늘은 ○○에 대해, 정답 말고 질문을 찾아보려고 해요."

**비주얼** (템플릿에 이미 적용됨)
- 포인트 색 `#FFD166`(따뜻한 노랑) + 짙은 남색. 상단 노란 박스 = 오늘의 질문, 흰 자막 + 검은 테두리
- 썸네일: 얼굴 + 12자 이내 문구 2줄, 마지막 줄만 노란색. 물음표로 끝나는 문구 우선
- 하단 워터마크 `@핸들`, 쇼츠 하단 진행 바, 마지막 2.5초 CTA 문구

## 5. 제목 공식 (택1)

1. **질문형**: "열심히 사는데 왜 불안할까?" (A·B 공통, 가장 기본)
2. **반전형**: "생산성 앱을 다 지웠더니 생긴 일"
3. **고백형**: "솔직히 저는 ○○를 몰랐어요"
4. **숫자형**: "하루 10분으로 생각하는 힘 기르는 법" (B 트랙)
5. **대화형**: "'그건 핑계야' vs '그건 상처야' — 친구와 싸울 뻔한 대화" (dialogue)

## 6. 주간 리듬 (매일 촬영 루틴)

| 요일 | 형식 | 트랙 | 내용 | 촬영 시간 |
|---|---|---|---|---|
| 월 | solo_short | A | 이번 주 화두 던지기 (내 관점 에세이) | 15분 |
| 화 | solo_short | B | 또래 고민 하나에 답하기 | 15분 |
| 수 | solo_short (2단계부터 dialogue_long) | B | 실천 팁 / (대화 롱폼) | 15분 / 40분 |
| 목 | solo_short | A | 내 경험 고백·실험 결과 | 15분 |
| 금 | solo_short | B | 댓글 질문에 답장 (2단계부터 실제 댓글) | 15분 |
| 토 | dialogue_short | A·B | 친구와 1분 토론 한 장면 | 20분 |
| 일 | dialogue_long | A | 주간 대화 (→ 쇼츠 3개가 다음 주 빈자리를 채움) | 40분 |

- **촬영 15분 공식**: 오늘 카드 읽기 3분 → 3번 연속 찍기 7분(제일 좋은 것만 inbox에) → 넣고 끝 5분
- 아침에 `python -m studio today` 로 카드 확인 → 찍기 → `inbox/` 에 넣으면 끝
- 몰아 찍기 허용: 주말에 평일 쇼츠 3~4개를 미리 찍어 날짜를 파일명에 붙여 넣으면(`2026-10-21_solo_short.mp4`) 그날 계획과 연결되어 예약된다
