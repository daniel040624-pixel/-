# 성장 플레이북 — 시기별로 가장 빠르게 구독자를 늘리는 방법

> **이 문서가 무엇인지 먼저 밝혀둡니다.** 공개된 연구 자료와 토론·인사이트·팟캐스트 채널에서 반복적으로 확인되는 성장 패턴을 종합한 **출발 가설**입니다.
> 비슷한 채널(구독자 1만+)의 실제 데이터는 `python -m studio benchmark "키워드" --ai` 로 수집해 이 문서를 검증·수정하세요 (아래 7장).
> 성장 속도를 보장하는 방법은 없습니다. 대신 **무엇을 측정하고, 언제 무엇을 바꿀지**를 정해 두는 것이 가장 빠른 길입니다.

## 0. 모든 단계에 공통인 5가지 원칙

1. **발견은 쇼츠, 전환은 롱폼.** 쇼츠는 처음 보는 사람을 데려오고, 롱폼은 그 사람을 구독자·팬으로 만든다. 1만 8천 개 채널을 분석한 연구에서도 쇼츠가 롱폼 성과를 깎는 효과는 큰 채널에서만 나타났고, 작은 채널에서는 차이가 거의 없었다 → **초기에는 쇼츠를 아낌없이.**
2. **클립은 반드시 원본을 가리킨다.** 팟캐스트 시청자 조사에서 클립을 본 사람의 84%가 "클립 때문에 정기 청취자가 된 적이 있다"고 답했고, 클립에서 전체 에피소드를 언급하거나 화면에 제목이 있을 때 원본을 가장 잘 알아봤다 → 모든 클립에 "전체 대화는 채널에서 ▶" CTA와 설명란 첫 줄 링크를 넣는다 (템플릿·업로더에 이미 자동 적용).
3. **첫 3초가 영상의 전부.** 인사·자기소개 없이 훅 문장으로 시작한다. 같은 주제라도 훅만 바꾸면 결과가 달라진다 → 훅을 실험 대상으로 다룬다.
4. **일관성은 빈도보다 '약속'이다.** 같은 시간, 같은 톤, 같은 질문으로 닫기. 시청자가 "이 채널은 이런 곳"이라고 한 문장으로 말할 수 있어야 추천도 구독도 빨라진다.
5. **매주 한 번, 데이터를 보고 하나만 바꾼다.** 한 번에 여러 개를 바꾸면 무엇이 효과였는지 모른다.

## 1단계 · 씨앗 (구독자 0~100) — "포맷을 검증하고 습관을 만든다"

**기간 목표**: 4~6주 안에 영상 30개. 이 단계의 진짜 목표는 구독자가 아니라 **나에게 맞는 훅 스타일 1개와 매일 찍는 습관**이다.

| 항목 | 운영 규칙 |
|---|---|
| 업로드 | 쇼츠 매일 1개 (19:00 예약), 일요일 대화 롱폼 1개 (→ 클립 3개) |
| 형식 비율 | 혼자 쇼츠 6 : 대화 1 (주간 리듬 표대로) |
| 트랙 비율 | A 40% : B 60% — 처음엔 사람들이 이미 찾는 고민(B)으로 발견되기 |
| 핵심 지표 | 쇼츠 **'계속 시청' 비율**(YouTube Studio → 쇼츠 피드에서 본 사람 중 넘기지 않은 비율), 평균 시청률. 롱폼은 첫 30초 이탈 |

**할 일**
1. 채널 세팅 (1회): 이름·핸들·배너·소개에 약속 한 줄 "매일 한 가지, 스스로 생각하게 만드는 질문"
2. **훅 A/B 실험**: 매주 같은 기둥의 주제를 질문형 훅과 고백형 훅으로 각각 찍어 비교
3. **일요일 10분 리뷰**: 이번 주 7개 중 1등 영상의 공통점을 `plan/review.md` 에 한 줄 기록 (`python -m studio listen` 으로 데이터 수집)
4. **진심 댓글 하루 3개**: 비슷한 채널 영상에 내 관점 한 줄을 댓글로 (홍보 문구 금지) — 1단계의 유일한 외부 유입이자, 대화 상대를 찾는 통로
5. 같은 쇼츠를 인스타 릴스·틱톡에도 올리기 (업로드 시 생성되는 `*_caption.txt` 사용)

**하지 말 것**: 지인에게 구독 부탁하기(관심 없는 구독자는 추천 신호를 흐린다), 10개 만에 포맷 바꾸기, 장비 구매

**다음 단계 신호**: 구독자 100명 **또는** 30개 중 평소 대비 3배 이상 조회된 영상이 1개 이상 → 그 영상이 2단계의 "위너 포맷"

---

## 2단계 · 발아 (100~1,000) — "터진 패턴을 시리즈로 증폭한다"

| 항목 | 운영 규칙 |
|---|---|
| 업로드 | 쇼츠 매일 1개, 롱폼 주 2개 (수·일 20:00) |
| 형식 비율 | 혼자 쇼츠 5 : 대화 쇼츠 1 : 대화 롱폼 2 (롱폼 클립이 쇼츠 빈자리를 채움) |
| 트랙 비율 | A 45% : B 55% — B 트랙 소재를 **실제 댓글**로 교체 |
| 핵심 지표 | **조회수 대비 구독 전환**, 롱폼 노출 클릭률 4% 이상, 평균 시청 지속률 35% 이상 |

**할 일**
1. **시리즈화**: 1단계 상위 20% 영상의 공통점으로 시리즈 이름을 붙인다 (예: "생각 실험 #1", "금요일 댓글 상담소")
2. **댓글 → 기획 루프**: 매주 `python -m studio listen` → `python -m studio plan` (댓글이 B 트랙 주제로 자동 반영)
3. **쇼츠 → 롱폼 다리**: 클립 설명란 첫 줄 링크(자동) + YouTube Studio에서 쇼츠의 '관련 동영상'에 원본 롱폼 지정(수동, 1분)
4. 롱폼 썸네일 2~3안 → YouTube Studio '테스트 및 비교'
5. 재생목록 3개: A 트랙 / B 트랙 / 대화 시리즈

**하지 말 것**: 조회수 낮은 영상 삭제, 주제를 채널 약속 밖으로 넓히기

**다음 단계 신호**: 구독자 1,000명 + 구독 전환이 꾸준히 오르는 시리즈 1개

---

## 3단계 · 성장 (1,000~10,000) — "다른 사람의 시청자를 데려온다"

| 항목 | 운영 규칙 |
|---|---|
| 업로드 | 쇼츠 하루 2개 (12:10, 19:00), 롱폼 주 2개 |
| 형식 비율 | 대화 비중 확대: 롱폼은 대화 위주, 롱폼 1편 → 쇼츠 4~5개 (`templates/dialogue_long.toml` 의 `clips = 5`) |
| 트랙 비율 | A 50% : B 50% |
| 핵심 지표 | 재방문 시청자 비율, 게스트편 유입 구독, 플랫폼별 팔로워 |

**할 일**
1. **게스트 대화 월 2회**: 비슷한 규모(구독 1천~3만) 크리에이터·다른 분야 실무자. 서로의 채널에 클립을 공유하는 조건으로 — 3단계에서 가장 빠른 성장 레버
2. **시즌제**: 4주 단위로 큰 질문 하나 (예: 시즌 2 "일의 의미") → 기획이 쉬워지고 몰아보기가 생김
3. **멀티플랫폼 본격화**: 릴스·틱톡 매일, 플랫폼별 반응 비교
4. **소유 채널 개설**: 뉴스레터나 오픈채팅 ("이번 주 질문" 메일). 조사에서 뉴스레터 구독자 87%가 메일로 에피소드에 돌아왔다
5. 수익화(YouTube 파트너 프로그램) 조건 점검

**다음 단계 신호**: 구독자 1만 + 게스트 없이도 롱폼 조회가 구독자 수의 10% 이상

---

## 4단계 · 확장 (10,000~100,000) — "나 없이도 돌아가는 시스템"

| 항목 | 운영 규칙 |
|---|---|
| 업로드 | 쇼츠 하루 2개, 롱폼 주 3개 (월·수·금) |
| 핵심 지표 | 구독자당 월 조회, 팬 비율(댓글 재참여자), 신규 vs 재방문 |

**할 일**
1. **제작 분업**: 촬영은 나, 편집 검수·업로드는 이 파이프라인 + 보조 인력 1명
2. **더 큰 게스트** 월 2회 + **시청자 참여 대화편**(구독자를 게스트로 초대) 월 1회
3. **라이브 Q&A** 월 1회 → 클립으로 재가공
4. 상위 10% 롱폼의 **후속편** 만들기 ("지난번 대화, 그 후")
5. **월간 데이터 리뷰**: `benchmark` 재실행 + `listen` → 이 플레이북 갱신

## 5. 가장 빠른 레버 요약

| 단계 | 1순위 레버 | 2순위 | 측정 |
|---|---|---|---|
| 0~100 | 매일 쇼츠 + 훅 실험 | 진심 댓글 | 계속 시청 비율 |
| 100~1천 | 위너 포맷 시리즈화 | 댓글 → 기획 루프 | 조회 대비 구독 전환 |
| 1천~1만 | 게스트 협업 | 롱폼 1편 → 쇼츠 5개 | 게스트편 유입 |
| 1만~10만 | 시스템화 + 큰 게스트 | 커뮤니티·라이브 | 팬 비율 |

## 6. 매주 루틴 (프로그램과 연결)

| 언제 | 명령 | 하는 일 |
|---|---|---|
| 매일 아침 | `python -m studio today` | 오늘 촬영 카드 확인 |
| 매일 촬영 후 | 영상을 `inbox/` 에 넣기 | `watch` 가 편집 → 시간표대로 예약 업로드 |
| 일요일 | `python -m studio listen` → `python -m studio plan --days 7` | 성과·댓글 수집 → 다음 주 계획 |
| 매월 1일 | `python -m studio stage` → `python -m studio benchmark "키워드" --ai` | 단계 확인(시간표 자동 전환) → 플레이북 검증 |

## 7. 비슷한 채널 실제 데이터로 검증하기

```bash
export YOUTUBE_API_KEY=...   # Google Cloud Console → YouTube Data API v3 → API 키
python -m studio benchmark "인사이트 토크" "생각 정리" "자기계발 대화" "철학 팟캐스트" --min-subs 10000 --ai
```

결과물 `research/benchmark.md`:
- 구독자 구간별(1만~10만 / 10만~100만 / 100만+) **주간 업로드 수, 쇼츠 비율, 롱폼 길이, 조회/구독 비율, 참여율** 중앙값
- **평소 대비 2배 이상 터진 제목 vs 절반 이하 제목**의 차이 (질문형·숫자·1인칭·인용 비율, 글자 수)
- 하루 구독자 증가가 빠른 채널 TOP 15와 그 채널의 인기 제목
- `--ai`: 위 데이터로 이 플레이북의 단계별 수정안 (`research/benchmark_insights.md`)

> 한계: API는 채널의 **현재** 구독자 수만 알려주므로 "하루 평균 증가"는 개설 이후 평균입니다. 과거 시점의 성장 곡선은 Social Blade 같은 외부 서비스로 보완하세요.
